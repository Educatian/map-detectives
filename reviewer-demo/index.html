Can a model trained here be trusted somewhere else?

A GeoAI learning-game prototype for middle-school students.

Students label aerial images, inspect a small model’s predictions, and test what changes when the model moves from the University of Alabama campus to Greensboro, Alabama.

What to look for

  1. Label land-cover examples and train the in-game classifier.
  2. Inspect predictions by class, including the model’s weak spots.
  3. Try the model in a different region and compare results after adding local examples.

Follow the game’s own prompts. Desktop Chrome or Edge is recommended. The initial download is approximately 15 MB; mobile and assistive-technology compatibility have not been established.

Prototype boundaries

This is a demonstration, not a research study. Use a made-up code name and do not enter personal information. Automated testing and simulated examples do not establish student learning gains. Automatically generated reference labels can contain errors. The heat activity displays a relative land-cover index, not measured cooling.

This entry page limits network connections to this site’s assets and disables Unity’s automatic persistent-data synchronization. The compiled prototype may still create browser-local records; this is not a complete storage/security audit. No research enrollment or data-upload service is added by this page.
